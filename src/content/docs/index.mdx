### Public campus platform

The canonical public API exposes versioned UTM buildings and places, deterministic building-to-building routing, and route-aware assessment of an explicitly supplied free interval.

- API base: `https://api.gapwise.ca/v1`
- OpenAPI 3.1: `https://api.gapwise.ca/openapi.json`
- Public developer hub: `https://gapwise.ca/developers`
- Source: `https://github.com/Gapwise-for-UofT/gapwise`
- JavaScript / TypeScript (npm): `npm install @gapwise/sdk@0.1.1`
- JavaScript / TypeScript (JSR): `jsr:@gapwise/sdk@0.1.1`
- JavaScript / TypeScript (GitHub Packages mirror): `@gapwise-for-uoft/sdk@0.1.1`
- Python: `python -m pip install gapwise==0.1.0`

Successful responses use `{ data, meta }`; errors use a nested structured error envelope with a request ID. Both official SDK implementations target the same v1 contract. `@gapwise/sdk@0.1.1` is published on npm and JSR, the same JavaScript SDK is mirrored publicly on GitHub Packages as `@gapwise-for-uoft/sdk@0.1.1`, and `gapwise==0.1.0` is published on PyPI through Trusted Publishing and has been independently clean-installed against the production API. The GitHub Packages mirror uses the organization-scoped package name required by GitHub and does not replace the canonical `@gapwise/sdk` identity.

### Canonical open campus data

Gapwise Data is the canonical repository for public University of Toronto campus facts and geometry. It owns campus-scoped building identity and footprints across UTM, UTSG, and UTSC. Its current production distribution adds reviewed UTM entrances, routing graph inputs, provenance, evidence state, uncertainty, and generated data audits.

Raw artifacts are published under:

```text
https://data.gapwise.ca/datasets/utm/latest/
```

Gapwise web/API builds do **not** live-fetch the Data website. They pin a validated snapshot so a Data-site or GitHub outage cannot break routing for students. See [Gapwise Data](/data/) and [Distribution and versioning](/data/distribution/).

### Permissioned Gapwise AI / MCP

Gapwise AI is a separate provider-neutral remote MCP service. The client supplies the model and reasoning layer; Gapwise supplies deterministic public-campus tools plus explicitly delegated private tools and bounded mutation semantics.

- MCP resource: `https://ai.gapwise.ca/api/mcp`
- OAuth protected-resource metadata: `https://ai.gapwise.ca/.well-known/oauth-protected-resource`
- AI service: `https://ai.gapwise.ca`
- Source: `https://github.com/Gapwise-for-UofT/ai`

The live release surface exposes **20 tools total**:

- **7 stateless public campus reads** for UTM building, place, route, and gap-window context;
- **12 permissioned private reads/planning tools** over explicitly delegated student context;
- **1 permissioned private write tool** for a bounded gap-preference update.

Public campus tools do not authenticate or expose a student's private timetable, friends, precise location, or sync state. Private tools require the production Gapwise OAuth/delegation boundary. Academic meetings remain read-only and cannot be created, edited, or deleted by an AI client.

Broad named-client compatibility is still a release gate. These docs do not claim ChatGPT, Claude, or another named client as fully verified until the production OAuth/read/write/revoke matrices are complete. See [Client compatibility](/ai/compatibility/).
